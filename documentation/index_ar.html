Sentry PM

منصة متكاملة لإدارة المشاريع (على غرار Jira) والمراقبة الحية لأخطاء الكود (على غرار Sentry). مصممة بواجهة داكنة متميزة (Vibrant-Glass)، ثنائية اللغة تدعم بالكامل العربية (RTL) بالإضافة إلى التواصل اللحظي والمحادثات المدمجة.

🚀 خطوات التثبيت

الطريقة الأولى — سكريبت التثبيت الآلي (الموصى بها)

أمر واحد يكفي للقيام بكل شيء:

# بعد تنزيل الكود وفك ضغطه، افتح الطرفية Terminal واكتب:
python install.py

وسيقوم السكريبت تلقائياً بـ:

  1. إنشاء ملف .env
    ينسخ القالب ويسمح لك بكتابة الإعدادات الخاصة بك.
  2. تثبيت المكتبات اللازمة
    ينفذ تثبيت حزم Python المطلوبة.
  3. تهيئة وإنشاء الجداول
    تشغيل أوامر الهجرة (Migrations) بشكل آلي على قاعدة البيانات.
  4. إنشاء حساب المدير العام
    ينشئ حساب admin برقم سري admin123 لتتمكن من الدخول الفوري.
  5. زرع البيانات التجريبية
    يتيح لك تعبئة النظام ببيانات وهمية كمشاريع تجريبية وأخطاء كود وأشخاص.
  6. إعداد الواجهة الأمامية
    يجلب حزم الـ Vue.js ويجهزها.

الطريقة الثانية — التثبيت اليدوي التقليدي

الخطوة 1: الخادم الخلفي (Backend)

# 1. إنشاء بيئة بيثون المعزولة
python -m venv venv
venv\Scripts\activate          # للويندوز
source venv/bin/activate       # لأجهزة الماك ولينكس

# 2. تثبيت الحزم
pip install -r requirements.txt

# 3. إنشاء ملفات البيئة
copy .env.example .env         # ويندوز
cp .env.example .env           # الماك ولينكس

# 4. ترحيل البيانات
python manage.py migrate

# 5. حساب الأدمن
python manage.py createsuperuser

# 6. إضافة الديمو (اختياري)
python demo_data.py

# 7. تشغيل السيرفر
python manage.py runserver

الخطوة 2: الخادم الأمامي (Frontend)

cd frontend
npm install
npm run dev     # خادم التطوير
# وعند الرغبة بالإطلاق للإنتاج:
npm run build   # توليد نسخة الإنتاج النهائية بداخل مجلد dist

إعداد الشبكة المحلية (LAN)

لجعل النظام متاحاً لكافة الموظفين على نفس شبكة الـ Wi-Fi:

# الخطوة 1: استخرج عنوان الآيبي الداخلي للجهاز المستضيف
ipconfig          # في الويندوز، ابحث عن IPv4 (مثال: 192.168.1.100)
hostname -I       # اللينكس وأجهزة التيرمنال المتقدمة

# الخطوة 2: شغل السيرفر ليقبل الاتصال من كل المنافذ الداخلية
python manage.py runserver 0.0.0.0:3535

# الخطوة 3: ادخل لملف الـ .env وعدل سطر الاستضافة:
ALLOWED_HOSTS=192.168.1.100,localhost

# الخطوة 4: شغل واجهة المشاهدين ليقبل الاستماع من الخارج
cd frontend && npm run dev -- --host 0.0.0.0
✅
النتيجة: أي شخص متصل بنفس الـ Wi-Fi يمكنه الوصول للنظام عبر: http://192.168.1.100:5173 — (مع استبدال الـ IP الظاهر بعنوان الخادم الداخلي الخاص بك).

🌐 النشر والاستضافة الشاملة للإنترنت (Production)

لتتيح Sentry PM لعملائك وموظفيك الموزعين عن بعد، ستحتاج نشره باستخدام إحدى هذه الخيارات الاحترافية:

الخيار الأول — منصة Railway.app (الأسهل، والأكثر ترشيحاً)

  1. ارفع الكود للـ GitHub
    اصنع مستودع خاص بك وارفع به مجلدات الكود.
  2. اربط به Railway
    اذهب لموقع railway.app ثم أنشئ بروجكت جديد يعتمد على استدعاء الكود من حسابك في الغيت-هب.
  3. ضع متغيرات الحماية والبيئة
    اضبط DB_ENGINE=postgresql والمتغيرات الأخرى ومفتاح الحماية كما ذُكر سلفا.
  4. تم الأمر! خذ الدومين الخاص بك
    سيرفر ريلوي سيعلمك حال جاهزية الروابط وسيولد لك رابط بـ HTTPS مؤمن فورا كالتالي https://sentry-pm-xxxx.railway.app.

الخيار الثاني — سيرفر تأجيري (VPS / AWS / DigitalOcean)

# 1. الدخول بالـ SSH للخادم المعزول:
ssh user@your-server-ip

# 2. تنزيل اللغات وتثبيت Nginx لاستضافة البيانات
sudo apt update && sudo apt install python3 python3-pip nodejs npm nginx -y

# 3. جلب النظام للسيرفر وبدء التثبيت
git clone your-repo /var/www/sentry-pm
cd /var/www/sentry-pm && python install.py

# 4. بناء الـ Vue.js ليكون مضغوطاً وجاهزاً للمستخدم النهائي
cd frontend && npm run build

# 5. تشغيل واجهة البيانات بواسطة نظام يقبل اتصال قنوات التراسل المباشرة (ASGI):
daphne -b 0.0.0.0 -p 3535 config.asgi:application &

# 6. تمرير الطلبات وربطها لاستقبال المواقع على الدومين (عبر ضبط nginx).
⚠️
ملاحظة للمستضيفين المشتركين الضعاف: ميزة إرسال الشات الحي ومزامنة الإشعارات تستدعي استخدام (Daphne/Websockets). الاستضافات التقليدية الضعيفة مثل (cPanel Shared Hosting) تعمل غالبا بـ WSGI لذلك ستفقد ميزات التحديث الفوري المبرمج.

ما الذي سيرصده ويصوره من تلقاء نفسه الآن؟

العملية والتدخل الخاطئالتقنية اللاقطة لهمكان الظهور في Sentry PM
أخطاء واكسبشنات الجافاسكربتيستمعه تلقائيا عبر اعتراض window.onerrorIssues → قائمة الاستثناءات
الأكواد الغير محلولة من فروع البرومساعتراض وعدم قبول unhandledrejectionIssues → قائمة الاستثناءات
فشل واستهلاك اتصال الشبكة (الباك-اند)خطف كل الدوال التي ترسل استعلام Fetch/XHRIssues → مسجل الشبكات
طباعات أو رسائل فاشلة في كونسول الإنتاجمراقبة دوال الـ Console للتعقبفي صفحة تفاصيل كل إيرور كإثبات
إعادة تصوير ما ارتكبه العميل للأسف بالفيديوعبر التحديث الحي والتسجيل بـ DOM المستمر بـ rrwebIssues → شاشة إعادة المشغل (Player)

كيف يتم نقل المعلومات تقنياً؟ (Data Flow)

Your App (Browser)
   ↓ JavaScript error occurs violently
   ↓ SDK captures the event: error msg + stack tree + last 20 sec replay recording
   ↓ POST req sent via fetch /api/capture/ to → Sentry PM API
      ↓ Incident is permanently persisted in the DB
      ↓ Triggers notifications for developers linked to that specific Project!
      ↓ Dev checks UI and taps "Replay Session" → watches the chaos unfold.

بالتأكيد! لتفعلها، توجه لملف البيئة .env وعدل القاعدة الافتراضية DB_ENGINE=sqlite ولن تحتاج للذهاب لأي مكان وتنزيل برامج. ننصح بها للبيئات وفرق العمل الصغيرة؛ بينما البوستجريسكيويل مخصص لقدرات استضافة وفرق أكثر شراسة.
تغلبني شاشة الشات والتقييم! هل هذا النظام يبُنى حقاً بنسخة العربية المعكوسة (RTL) أم هو عبارة عن ترجمة شاشات ركيكة فقط؟ ▼
ندرك تماماً حجم المعاناة العربية بالأنظمة الغربية؛ قمنا بكتابة وهيكلة المتغّيرات والـ CSS خصيصاً للتبديل المنطقي لكل المساحات ومواضع المحاذاة. إذا قمت بالتبديل للغة العربية من إعدادات المستخدم، سيميل كل النظام وواجهاته بالكامل من اليمين ولأجل لغة الضاد بدون أي اختلال وبجودة بصرية لا تُضاهى.
كيف يمكن استعادة ديمو النظام بعد حذفه أثناء استعراضه؟ ▼
وفرنا لك مجدداً أمر python reset_demo.py سيطلب منك بالإنجليزية تأكيد كلمة RESET. لو وافقت سيبتر النظام كامل المشاريع، الرسائل والبيانات المعطلة ويضخ مئات الجداول المثالية التي تبهر أي عميل للتطبيق.
هل أحصل على الشفرات المصدرية المفتوحة بالكامل لنواة المنتج؟ ▼
بطبيعة الحال، كلا المجلدين الأساسيين للخادم الخلفي (Django Back-end) وأوامر التطبيق الأمامي المطور بالكامل (Vue.js Front-end) في أيديك الشريفة بشكل مفتوح وموثوق وخالي من الاحتكار وتستطيع التلاعب أو حذفه بالكامل وبناء واجهات أو تعديلات غير مشروطة للتربح منها بحسب التراخيص.
